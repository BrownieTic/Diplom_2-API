# Diplom_2

Набор API-тестов для сервиса Stellar Burgers. Тесты написаны на Python с использованием `pytest`, `requests` и `allure-pytest`; запросы отправляются к сервису, указанному в `urls.py`.

## Структура проекта

- `tests/test_user.py` — тесты регистрации пользователя и авторизации.
- `tests/test_order.py` — тесты создания заказа: с авторизацией и без неё, с пустым списком ингредиентов и с неверным ID ингредиента.
- `api/user_api.py` — отправка запросов на регистрацию, удаление пользователя и вход.
- `api/order_api.py` — отправка запросов на создание заказа.
- `conftest.py` — фикстуры pytest: генерация данных пользователя, создание и удаление пользователей, подготовка API-клиентов и списка ID ингредиентов.
- `data.py` — данные пользователя и ингредиентов.
- `randomizer.py` — генератор случайных строк для тестовых данных.
- `urls.py` — базовый адрес сервиса и адреса API endpoint'ов.
- `requirements.txt` — список Python-зависимостей проекта.

## Требования

- Python 3
- Доступ к тестируемому сервису
- Пакеты `pytest`, `requests` и `allure-pytest`
- Allure Commandline — только для просмотра Allure-отчёта

## Установка

В PowerShell из корневой папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pytest requests allure-pytest
```

## Запуск тестов

Запустить весь набор:

```powershell
python -m pytest
```

Запустить конкретный файл:

```powershell
python -m pytest tests\test_user.py
python -m pytest tests\test_order.py
```

Проверить сборку тестов без отправки запросов:

```powershell
python -m pytest --collect-only -q
```

Тесты обращаются к реальному сервису, поэтому для их выполнения он должен быть доступен. Проверка `--collect-only` только обнаруживает тесты и не проверяет доступность сервиса или корректность ответов API.

## Allure-отчёт

Сохранить результаты запуска и открыть отчёт локально:

```powershell
python -m pytest --alluredir=allure-results
allure serve allure-results
```

Для этих команд, помимо Python-пакета `allure-pytest`, в системе должна быть установлена Allure Commandline.

## Примечание

Адрес тестируемого сервиса задаётся в `urls.py`. Учётные записи создаются во время тестов; фикстуры удаляют созданных пользователей после завершения соответствующего теста. Результат проверки зависит от доступности сервиса и соответствия его ответов ожиданиям, заданным в тестах.
